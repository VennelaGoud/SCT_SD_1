# Temperature Converter

A user-friendly Temperature Converter application developed using Java Swing. This application allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin through an interactive graphical user interface (GUI).

## Features
- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Simple and intuitive GUI
- Input validation and error handling
- Clear button to reset inputs

## Technologies Used
- Java
- Swing
- AWT
- Event Handling

## How to Run
1. Compile the program:
   javac TemperatureConverter.java

2. Run the program:
   java TemperatureConverter
